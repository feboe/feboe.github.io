challenge: Develop a robust and traceable workflow for parameterizing an electric-motor thermal model from measurement data.
approach:
  - Developed a MATLAB calculation tool around a time-discrete thermal simulation solved with the explicit Euler method.
  - Used weighted regression, multiple starting values, and a structured data-preparation workflow to improve parameter robustness.
  - Connected the tool to the existing data-processing application and documented a repeatable parameterization procedure.
outcomes:
  - The MATLAB tool connected to the existing data-processing application and entered active development use.
  - The documented workflow provided a repeatable best-practice basis for thermal-model parameterization.
